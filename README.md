A simple HTML file that takes the Distrokid royalty data export and transforms it into a useful, insightful dashboard.

The data from Distrokid can be useful, but the current dashboarding is terrible. This simple HTML file works off a legacy Excel file to take that data and transform it into actionable insights.

**Current features include:**
1. By store/region/song/artist information
2. Multi-Artist accessibility (switch betwen artists without filtering impmorted data)
3. Dive deeper into sub-stores (e.g. Apple Music/iTunes Songs/iTunes/iTunes Match)

# **How To Export Data**

*Correct as of 9th November 2026*

Go to **https://distrokid.com/bank/details/** and click the download button at the top right

<img width="184" height="41" alt="image" src="https://github.com/user-attachments/assets/2cbca09f-8637-4da5-9afc-0cfac52eb6fe" />

Then click the ***Request Bank Report*** button on the next page.

<img width="1175" height="439" alt="image" src="https://github.com/user-attachments/assets/8b64a3c4-7cf1-4282-8643-e1f1490a86de" />

Don't change any filters (not necessary) and click ***Generate***

<img width="433" height="487" alt="image" src="https://github.com/user-attachments/assets/0f0652a1-0840-4455-8894-bdb4b087bbac" />

You will see an indicator that the report has been requested. Click ***Okay*** to refresh the page and see that your report is now being generated. Wait for it to change to a ***Download*** button then click to download the file.

# **Using the Dashboard**

Open the file in your preferred browser (Chrome works best) then click and drag your exported file into the page, or click to select your file in File Explorer. (You will see the Light Mode/Dark Mode option here too, that little asterisk carries throughout the file so you can change when needed.)

<img width="809" height="678" alt="image" src="https://github.com/user-attachments/assets/a13f1c02-a94e-4dfa-bc60-ad5162d0d59a" />

The first screen you will enter to is an **Overview** which shows:

1. All Time/All service data (Hover over line graph for specific month data)
2. Top Service/Country/Track and Catalog Summary
3. Top Tracks by Earnings
4. Service Mix by % of total earnings

Additionally, the following options are available on any of the three dashboards:
A. Artist switch (appepars if more than one artist in data)
B. Dashboard toggle
C. Dark/Light Mode Switch
D. Load New File

<img width="1173" height="813" alt="Screenshot 2026-11-09 085335" src="https://github.com/user-attachments/assets/293dff3d-566c-4af3-b038-3ee9327aa133" />

The second screen is **Earnings**, the third is **Listens** - both allow you  to view the same data by store but with one screen focused on earnings and the other on listens. This can be useful for gauging which stores have the most exposure versus which ones pay better. 

This page includes:

1. Store Selector (With option to breakdown into sub-stores)
2. Earnings by Country (Can click to focus on specific bubble)
3. Earnings Over Time
4. Key Store Data
